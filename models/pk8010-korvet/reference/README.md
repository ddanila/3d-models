# ПК8010 Корвет reference material

Local research references collected on 2026-10-06 for the replacement keycap
project. These are third-party materials, not original project designs.

## User-supplied keycap reference

[Four original keycap photographs and measurement notes](user-photos/README.md)
show the loose ↑/8 keycap, including its underside. The user measured the
inner mounting opening as **5.5 × 3.5 mm**. These are the primary references
for the keycap geometry; the internet material below provides context.

[Five wide РГ / SHIFT key photos](wide-key-photos/README.md) provide the
separate wider outline and row-profile reference. Their archive contains no
underside view, so the SHIFT mount remains provisional.

## Keyboard and case photographs

Source: [Корпус и клавиатура от КОРВЕТ ПК 8010 СБ8010](https://ibb.co/album/5Kh88z),
uploaded by **leman** on ImgBB. Original JPEG files are in `photos/`.
The album advertises 19 images, but its public listing exposes 14 originals
(including when sorted oldest first). Only those accessible images are archived.

Use these photographs to study the keyboard layout, key profiles, and case.
They are not calibrated measurement references. See `photos-contact-sheet.jpg`
for an overview; use the originals for detail.

Useful starting views: `IMG-20260130-124126.jpg` shows the key profiles from
the side; `IMG-20260130-124106.jpg` and `IMG-20260130-124123.jpg` show closer
views of the left and right key groups. None shows a removed keycap's mount.

## Related CAD references

Source: [Все о Корвете — 3-D модели](https://pk8020.ru/Hard/3d).
The `cad/` directory preserves the available PNG previews, КОМПАС-3D `.m3d`
files, and STL meshes for:

| Filename stem | Part |
| --- | --- |
| `SB80xx_reset1` | Right side panel for the round reset button |
| `SB80xx_reset2` | Right side panel for the rectangular reset button |
| `SB80xx_reset_button1` | Classic reset button |
| `SB80xx_reset_button2` | Rectangular reset button |

The source marks both reset buttons and the rectangular-button panel as
unprinted and not checked for dimensional accuracy. Its ordinary keyboard
button models remain listed as planned work. These reset-button files do not
establish dimensions or mounting geometry for an ordinary keyboard keycap.
PNG files are model previews, not dimensioned engineering drawings.

Cyrillic `х` characters in downloaded CAD filenames have been normalized to
Latin `x`; original URLs are retained in `sources.json`.

## Provenance

`sources.json` records source URLs or the user-supplied archive, byte sizes, and
SHA-256 checksums. Internet files are retained as downloaded. The contact sheet
is generated; user-photo copies have EXIF metadata removed without changing
their image pixels. No reuse license has been established for the internet materials;
keep their third-party provenance when using them as local design references.

No verified regular-keycap dimensions were found in the internet sources.
The user-supplied socket measurement is recorded above; the remaining dimensions
and photo estimates are tracked in the user-photo notes.
