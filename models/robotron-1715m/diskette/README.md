# Owner diskette and storage sleeve

**Not physically verified.** Visual reference modeled from Danila’s six photos
in `Photos-1-001 (10).zip`, received 2026-10-13. Photos are owner-provided under
this repository’s MIT license; originals and hashes are in `../reference/`.

- `113451775`: label side; `113457457`: reverse (all filenames start `PXL_20261013_`).
- `113428737`: plain sleeve side; `113436448`: printed sleeve side.
- `113529099`: inserted disk, lever horizontal/open.
- `113537277`: same disk inserted, lever down/closed.

The white storage sleeve is the one the owner uses, **not original packaging**.
The black disk jacket stays in the drive; the white storage sleeve does not.

Geometry uses the nominal 133.35 mm jacket as a scale reference. Rounded head
window (about 12.5 × 35.5 mm), offset index aperture, two edge notches,
write-protect notch, small corner label and reverse folds follow the photos.
Thickness, seam depth and envelope dimensions remain estimates. Wear is omitted.
The museum projects only the identifying handwritten label; it does not paste
an entire photograph over the jacket. OpenSCAD shows the label as a plain shape.
The standalone review includes the separate plain white envelope; its printed
handling instructions remain available in the reference photo.

Insertion and clamping are distinct: the museum’s normal loaded state is closed;
“Release clamps” shows an inserted disk with the lever open without ejecting it.
The electronic head-load signal remains separate from manual clamp inspection.
This is a visual model, not a printable working magnetic disk.
